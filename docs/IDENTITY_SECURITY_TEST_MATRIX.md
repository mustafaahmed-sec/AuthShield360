# Identity Security Test Matrix

**Project:** AuthShield 360 fictional school portal
**SRS:** Version 1.0, sections 1.2 and 1.6–1.9
**Evidence date:** 2026-09-30
**Local environment:** Django test settings with in-memory SQLite. SMTP and Firebase delivery/verification are simulated except where explicitly identified as live configuration checks. No production sign-in or live SMS was performed.

The SRS requires Test ID, User/Role, Test Action, Expected Result, Actual Result, Pass/Fail Status, and Evidence. This matrix records those fields and keeps automated results separate from live/manual checks.

## Local verification

On 2026-09-30, the complete Django suite ran with `config.test_settings`: **127 tests passed**. Ruff passed for `accounts`, `config`, and `school`; `makemigrations --check --dry-run` reported no model/migration drift. The tests use disposable in-memory SQLite, local/mock email, simulated Firebase, and mocked OIDC; they do not prove live provider delivery, hosted authenticated browser behavior, or the deployed portal version.

```powershell
.\.venv\Scripts\python.exe manage.py test --settings=config.test_settings --noinput
.\.venv\Scripts\ruff.exe check accounts config school
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run --settings=config.test_settings
```
